# Stadium viewport moods

Original Trackmania 2020 Stadium GameData resources, supplied from the local extracted game installation for the requested Item Studio viewport preview. Copyright belongs to Ubisoft/Nadeo; these game resources are not covered by the repository code license.

Four folders contain only Mood.MoodSetting.xml, SkyColor.dds, SkyClouds.dds and EnvCubicHdr.dds. manifest.json records source, size and SHA-256 for each file. Total uncompressed asset size is approximately 16 MiB. Assets load on demand from the site's base URL. They are not included in exported items and do not change a map's mood.

Rendering in Three.js approximates the game's sky/environment/light settings; it does not reproduce the Trackmania renderer. If the user selects local GameData, matching local files take priority.
