# Approved external-mesh diagnostic fixture

`Cat.Item.gbx` was supplied by the user and explicitly approved on 2026-09-14
for testing, repository inclusion and screenshots. Its original metadata is
retained. It is a game-derived item, not a public-domain synthetic shape.

This fixture intentionally contains legacy mesh/shape filenames without those
dependency files. The regression verifies that diagnostics distinguish missing
geometry from an unavailable texture, and list `Meshes\Cat.Mesh.gbx` without
attempting filesystem/network resolution. No native-validity claim is made for
this standalone archive or its original non-TM2020 collection.
