# Native embedded FX patch probe

This probe uses the `gbx-py`/NICE schema shipped with the BlenderMania
community importer to make the first narrow, native-field edit to an embedded
`CPlugFxSystem` item. It is intentionally separate from the browser studio and
from the normal GBX.NET writer because GBX.NET 2.x currently has no typed
`CPlugFxSystem` node.

Both Pyramid and Diamond candidates are Fogger-derived; changing their mesh
does not create Sparkler particles. Real Sparkler candidates are generated by
[`Tests/FxStandalone`](../FxStandalone/README.md).

The generator reads the embedded `FogVolumetric1_FogEmissionRate_0` fixture,
keeps its native `CPlugFxSystem` graph, and edits:

* `CPlugFxSystemNode_ParticleEmitter.LocalOffsetExpr` (the actual native FX
  emitter position, for example `float3(0,1.5,0)`),
* the first prefab entity's `CPlugStaticObjectModel.Mesh` (a typed Pyramid or
  Diamond mesh shell), and
* the outer item identity/name.

The result is reparsed by gbx-py and a manifest records the graph field and
hashes. Native Fids preload and placement are separate game-side checks; a
successful Python parse is not native runtime proof.

`gbx-py` and `construct` must be installed. On this machine the source schema
is at `C:\Users\PC\Downloads\Blender Addons\blendermania-addon\blendermania-addon\NICE`.

```powershell
python Tests/FxNativePatch/generate.py `
  --output artifacts/fx-clones/fx-native-patched-20261025 `
  --fog-rate 0
```

The generator refuses an FX carrier without the expected embedded graph or a
mesh shell with a typed `CPlugStaticObjectModel` node. It never contacts the
game and never changes files outside the output directory.

For the native offset isolation test, use `raw_patch.py` on the exact native
Save-As clones. It replaces the one serialized nine-byte `LocalOffsetExpr`
marker (`float3(0)` to `float3(1)`) in the **decompressed body**, after validating
the model terminator, null JointName, and ten-expression ParticleEmitter tail.
It preserves the header/reference table and all other decompressed body bytes.
The Fogger clone is uncompressed; the Sparkler clone is LZO compressed. A
compressed file is recompressed, so its compressed bytes and total file size
may change. Earlier raw-ASCII-in-LZO results are superseded by this version:

```powershell
python Tests/FxNativePatch/raw_patch.py `
  --fogger artifacts/fx-clones/native-embedded-20261025/TMIS_FoggerEmbeddedNativeClone.Item.Gbx `
  --sparkler artifacts/fx-clones/native-embedded-20261025/TMIS_SparklerEmbeddedNativeClone.Item.Gbx `
  --output artifacts/fx-clones/fx-native-offset-probe-20261025
```

Those offset probes retain the identity and reference layout of Editor++
Save-As; only the native emitter expression differs in the decompressed graph.
This does not restore missing particle texture dependencies. The real-source
Sparkler texture probes under `Tests/FxStandalone` address that separate issue.
