- **Purpose:** local DEV material diagnostics. The current comparison branches inspect fixed shader-reference candidates and their native structured-buffer flags. They do not write GPU/visual flags. A separate fixed-map placement branch and an older material-array alias branch remain independently gated.
- **Target/tested scope:** Trackmania 2026.2.2.1751 / engine 2026-02-02 17:51:19, Openplanet 1.29.14 Next/Public 6fd4200f. Revalidate all raw offsets after updates.
- **Publication intent:** local-only, do not publish.

The legacy alias gate was absent throughout this round. Legacy mutation owns borrowed buffers and restores them before releasing owner/target handles on every terminal path, disable, or destruction. No main window; demo UI N/A because the evidence is native loader state, logs, and a real game scene.

The diagnostic plugin and GPU helper were absent during the recorded animation.
