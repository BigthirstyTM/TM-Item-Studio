# Native planar bend regression

`planar-bend-native.json` records 425 authored positions and 1,403 collision
positions generated by Trackmania for the reported Mesh Modeler staircase.
The fixture contains numeric geometry only; source hash and engine provenance
are included in the JSON. The original item is not required to run this test.

The ItemScene suite measures each evaluated authored position against the
nearest native collision vertex (maximum allowed distance 0.01 metres).
This is a position regression, not a proof of render tessellation, topology,
textures, or arbitrary deformation controls.

The opt-in `SnapshotCrystalCollision` function in the Openplanet smoke plugin
captures the native oracle through typed, read-only engine fields. See
`docs/gbx-net-2.5-native-2026-10-30.md` for the procedure and limitations.
